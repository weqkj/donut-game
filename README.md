# 🍩 Donut Game

Telegram Mini App: кейсы, лидерборд, профиль, ракета (provably fair, SHA-256), апгрейдер, промокоды/чеки, задания, вывод.
Валюта donut — виртуальная. Пополнение только Telegram Stars: **1 ⭐ = 18 donut**.

```
docs/   сайт для GitHub Pages (весь проект)
```

Сейчас проект работает **только как сайт** (`API_URL` пустой в `docs/js/config.js`): баланс и кейсы хранятся локально в браузере (демо-режим).
Без сервера нет: настоящих платежей Stars, общего лидерборда, ответов бота на /start, защиты от накрутки.

## Токен бота
Токен бота **нельзя** класть в репозиторий или на GitHub Pages, даже «спрятанным»: любой откроет код сайта и достанет его.
Серверная часть (бот, Stars, баланс) была в папке `worker/`, её можно вернуть из истории: `git show 8c6b378:worker`.

## Приветствие без сервера (через BotFather)
- `/setdescription` — текст «Добро пожаловать! Играть можно по кнопке ниже», его видно до первого запуска.
- `/setmenubutton` (или `/newapp`) — кнопка «Играть» с адресом `https://weqkj.github.io/donut-game/`.

## Ассеты
`docs/assets/{dog,gifts,rockets}/*.webp` — анимации. Пёс/подарки играют один раз (тап — снова), ракета — бесконечно.
Цены подарков — `docs/data/gifts.json`, кейсы — `docs/data/cases.json`.
